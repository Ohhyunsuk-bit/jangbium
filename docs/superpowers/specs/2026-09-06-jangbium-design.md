# 장비움 — 대장내시경 장정결 스케줄러 설계 스펙

작성일: 2026-09-06
상태: 사용자 검토 대기

## 1. 목적

대장내시경 검사 일시와 처방받은 장정결제를 입력하면, 전날 식이부터 당일 복용 완료까지 개인화된 시간표를 만들어 주는 정적 웹 도구.

이 프로젝트는 1인 사업 연습이다. 목표는 "만들고 → 웹에 올리고 → 모르는 사람이 검색으로 찾아와 쓰는지 확인"하는 루프를 한 번 끝까지 돌리는 것이다. 지인 영업은 하지 않는다.

**성공 기준**: 배포 후 30일 안에 `plan.html` 조회(= 시간표를 실제로 만든 횟수) 100회. 달성하면 제품 추가·2차 기능으로 넓히고, 미달이면 유입 경로를 분석한다.

## 2. 범위

### 1차 버전에 포함
- 제품 3종: 쿨프렙산(2L PEG), 오라팡정(28정 OSS), 플렌뷰산(1L)
- 입력: 검사 날짜·시간, 제품
- 출력: 시각순 타임라인(D-1, 당일), 경고 배너, 링크 공유, .ics 캘린더 저장
- 제품별 검색 진입 페이지(설명 + FAQ)
- Cloudflare Pages 배포, Cloudflare Web Analytics 측정

### 1차 버전에서 제외 (명시)
- 브라우저 푸시 알림
- 오후 검사용 당일 단회 복용 경로
- 병원별 복용 시각 커스터마이즈
- 다른 제품(크린뷰올·수프렙미니·피코라이트 등)
- 카카오 SDK 연동
- 다국어
- 서버·계정·데이터 저장 일체

## 3. 사용자 흐름

1. 검색("쿨프렙 복용 시간")으로 `coolprep.html` 진입, 또는 `index.html`에서 제품 선택
2. 검사 날짜·시간 입력 → "시간표 만들기"
3. `plan.html?p=coolprep&t=2026-09-10T09:00` 으로 이동, 타임라인 표시
4. 하단 바에서 캘린더 저장 또는 링크 공유(카톡 등)
5. 공유받은 사람은 같은 URL을 열면 동일한 타임라인을 본다

## 5. 제품 데이터 (`protocols.js`)

### 5.1 공통 규칙
- **1차 복용(전날 저녁)**: 시작 시각 고정 19:00. 허가사항은 "검사 전날 저녁"으로만 명시하고 병원마다 18~22시로 다르므로 기본값 하나를 두고 "병원 안내가 있으면 그것이 우선" 고지.
- **2차 복용(당일)**: 마지막 단계 완료 시각 = 검사 시작 2시간 전. 여기서 단계 소요 시간을 역산해 시작 시각을 구한다. 마지막 복용 시작은 검사 5시간 이내여야 하며, 아래 3종은 모두 이 창 안에 들어온다(3~3.5시간 전 시작).
- 근거: 유럽 내시경학회 장정결 권고 2019(현행 최신판, 2026-09-06 확인), 미국 USMSTF 업데이트 2025년 3월(확인). 두 판 모두 분할 복용, 2시간 전 완료·5시간 이내 시작, 전날 하루 저섬유식을 권고.

### 5.2 제품별 단계 (허가사항 기준)

| 제품 | 2차 복용 단계 | 소요 | 2차 시작 |
|---|---|---|---|
| 쿨프렙산 | 조제 용액 1L를 60분간(15분마다 250mL) → 물 500mL를 30분간 | 90분 | 검사 3시간 30분 전 |
| 오라팡정 | 14정을 물 425mL와 30분간 → 이후 60분간 물 425mL×2 | 90분 | 검사 3시간 30분 전 |
| 플렌뷰산 | 2차 용액(A+B) 500mL를 30분간 → 물 500mL를 30분간 | 60분 | 검사 3시간 전 |

1차 복용(전날 19:00 시작)은 각 제품의 동일 단계 구성을 따른다(쿨프렙 1L+물 500mL, 오라팡 14정+물, 플렌뷰 1차 용액 500mL+물 500mL).

출처 확인 상태:
- 쿨프렙산: 약학정보원 용법용량 원문 확인됨
- 오라팡정: 허가 요약(닥터나우 의약품사전) 확인됨. 식약처 원문 페이지는 스크립트 렌더링이라 미확인 — **구현 단계에서 브라우저로 원문 확인 필요**
- 플렌뷰산: 검색 요약으로 부분 확인 — **구현 단계에서 식약처 원문 확인 필요**

### 5.3 식이 이벤트 (제품 공통)
- D-1 아침·점심: 저잔사식. 피할 음식 목록 표시
- D-1 저녁: 1차 복용 시작 3시간 전(16:00)까지 가벼운 유동식(미음·맑은 국물), 이후 맑은 음료만
- 당일: 맑은 음료만. 2차 복용 완료 후 검사까지 물 포함 금식
- 제품 페이지와 결과 상단에 고지: "병원에서 더 긴 식이 제한을 안내받았다면 그것을 따르세요"

### 5.4 임상 문구 초안 — 사용자(소화기내과 전문의) 감수 필요
아래는 구현 전에 사용자가 확정한다. 확정 전 코드에 넣지 않는다.

- 저잔사식에서 피할 음식: 씨 있는 과일(키위·딸기·포도·토마토), 잡곡·현미, 해조류(김·미역), 나물·채소 섬유질, 견과류, 김치·깍두기, 붉은 고기 다량
- 저잔사식 권장: 흰죽·흰밥, 계란, 두부, 맑은 국, 살코기 소량, 껍질 벗긴 감자
- 맑은 음료 허용: 물, 맑은 이온음료(무색), 보리차. 우유·주스(과육)·커피 크림·붉은색 음료 금지
- FAQ 초안 항목: 복용 중 구토했을 때 / 변이 맑아지지 않을 때 / 평소 약(혈압약·당뇨약·항응고제) 복용 여부 / 검사 후 식사 시점 — 각 답변은 "담당 의료진에게 문의"로 마무리하고 구체적 의학 판단은 넣지 않는다

## 6. 계산 (`schedule.js`)

```
computeSchedule({ examAt: Date, productId: string, now?: Date })
  → { events: Event[], warnings: Warning[] }

Event = { at: Date, end?: Date, day: 'D-1' | 'D0', kind: 'diet' | 'dose' | 'water' | 'fast' | 'exam',
          title: string, detail: string }
Warning = { code: 'PAST' | 'TOO_SOON' | 'EARLY_MORNING' | 'ODD_TIME', message: string }
```

- 순수 함수, DOM·전역 상태 없음. `now`는 테스트 주입용.
- 시간대: 브라우저 로컬. 한국은 서머타임이 없어 단순 산술로 충분.
- D-1 = 검사일의 전날(자정 넘김 처리 포함).
- 경고 조건:
  - PAST: examAt < now
  - TOO_SOON: examAt − now < 2차 복용 시작까지 필요한 시간(2차 시작 시각이 이미 지남)
  - EARLY_MORNING: 2차 시작이 05:00 이전
  - ODD_TIME: 검사 시각이 06:00 이전 또는 20:00 이후
- events는 시각순 정렬. 마지막 이벤트는 kind 'exam'.

## 7. URL 스키마

`plan.html?p=<productId>&t=<YYYY-MM-DDTHH:mm>`

- `p`가 없는 제품이거나 `t`가 파싱 불가 → 안내 문구 + `index.html` 링크. 계산하지 않는다.
- URL은 공유 링크 그 자체. 서버 없이 재현.

## 8. 캘린더 (`ics.js`)

- VCALENDAR 하나에 VEVENT 3개: D-1 08:00 저잔사식 시작, 1차 복용 시작, 2차 복용 시작
- 각 VEVENT에 VALARM 30분 전
- TZID Asia/Seoul, UID는 `p`·`t` 기반 결정적 문자열(같은 링크 → 같은 UID로 중복 방지)
- 다운로드: Blob → `<a download>`. 파일명 `장비움-<제품>-<날짜>.ics`

## 9. 화면

- 모바일 우선, 한 열, 큰 글씨. 검사 전날 밤에 폰으로 보는 상황을 기본으로.
- 제품 페이지: 제품 설명 2~3줄 → 날짜·시간 입력(시간 15분 단위) → 버튼 → FAQ
- 결과 페이지: 경고 배너(있을 때) → "D-1 (날짜·요일)" 묶음 → "검사 당일" 묶음 → 각 카드에 시각 배지·제목·설명 → 하단 고정 바 [캘린더 저장] [링크 공유] → 푸터(면책·감수자·출처)
- 공유: `navigator.share` 지원 시 공유 시트, 아니면 클립보드 복사 + 토스트
- 접근성: 버튼 기반, 포커스 가시, `prefers-reduced-motion` 존중

## 10. 검색

- 제목·설명 예: "쿨프렙 복용 시간표 계산기 — 검사 시간만 넣으면 끝 | 장비움"
- 구조화 데이터: WebApplication + FAQPage
- OG 이미지 1종(정적 PNG), sitemap.xml, robots.txt
- 카카오톡 미리보기에서 한글·OG가 제대로 보이는지 배포 후 확인

## 11. 표기·법적

- 브랜드: 장비움. 감수: "소화기내과 전문의 <실명>" — 소속 병원명은 표기하지 않는다.
- 면책(전 페이지 푸터 고정): "이 도구는 정보 제공 목적이며 진단·처방이 아닙니다. 병원에서 받은 안내가 있으면 그것을 따르세요."
- 출처: 각 제품 허가사항 페이지 링크
- 개인정보: 수집하지 않는다. 분석은 Cloudflare Web Analytics(쿠키 없음) → 처리방침·동의 배너 불필요
- 의료광고: 홍보하는 의료기관이 없으므로 해당 없음. 개원 후 병원과 연결할 경우 그때 재검토
